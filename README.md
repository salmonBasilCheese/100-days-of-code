# 100 Days of Code - Python Learning Journey

Pythonの言語仕様、オブジェクト指向設計、イベント駆動アーキテクチャの習得を目的とした実践プロジェクト集です。
構文の丸暗記ではなく、要件定義フレームワーク（主語・インターフェース、境界制約、データ制約、非機能要件）に基づいた設計駆動での開発を行っています。

## Projects List
- **coffee_machine**: オブジェクト指向プログラミング（OOP）による状態遷移とリソース管理
- **etch-a-sketch**: イベント駆動アーキテクチャと描画/UIの責務分離
- **hirst_painting**: RGBカラー抽出とタートルによる幾何学的ドット描画
- **quiz_brain**: モデル・データ・ロジックの分離（MVC概念の基礎）
- **turtle_race**: 状態遷移管理（READY/RACING/FINISHED）と公平な周回距離アルゴリズム（楕円軌道）
- **snake_game**: グリッド座標管理、キュー構造によるセグメント追従、排他入力制御
