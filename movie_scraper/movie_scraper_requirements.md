# システム要件定義書: 100 Movies Scraper

## 1. システム概要
### 1.1 目的
本システムは、Empire誌が選出した歴代ベスト映画100作品（Webアーカイブ版）から映画タイトル情報を自動抽出・整形し、指定のソート順（1位から100位への昇順）でローカルテキストファイル（`movies.txt`）へ出力することを目的とする。

### 1.2 背景・開発スコープ
- **背景**: 動的に変化またはレイアウト刷新されたWebサイトではなく、過去の静的アーカイブ（Wayback Machine）をスクレイピング対象とすることで、データ構造の安定性を担保する。
- **スコープ**:
  - 対象WebページのHTML取得
  - DOM解析による映画タイトル要素の抽出
  - 順序反転（降順から昇順への変換）および文字列整形
  - `movies.txt` へのファイル書き出し

---

## 2. 機能要件 (Functional Requirements)

| 機能ID | 機能名 | 詳細説明 | 期待される入力 / 出力 |
| :--- | :--- | :--- | :--- |
| **FR-01** | **HTML取得機能** | 指定されたWayback MachineのアーカイブURLへHTTP GETリクエストを送信し、HTMLレスポンスを取得する。 | 入力: 対象URL<br>出力: HTML文字列（ステータスコード200） |
| **FR-02** | **DOM解析・抽出機能** | BeautifulSoup（パーサー: lxml/html.parser）を用い、対象HTMLから全100件の映画タイトル要素（`<h3>`タグまたは該当クラス）を抽出する。 | 入力: HTML文字列<br>出力: 映画タイトル（生データ）のリスト |
| **FR-03** | **データ整形・ソート機能** | ページ内で100位から並んでいるタイトル順序を反転し、1位から100位への昇順に並べ替える。各行の余計な空白・改行を除去する。 | 入力: 降順映画タイトルリスト<br>出力: 昇順映画タイトルリスト（100件） |
| **FR-04** | **テキストファイル出力機能** | 昇順に並べ替えたタイトル一覧を、`movies.txt` としてUTF-8エンコーディングで保存する。各行は改行コード（`\n`）で区切る。 | 入力: 昇順映画タイトルリスト<br>出力: `movies.txt` |

## 3. 非機能要件 (Non-Functional Requirements)

### 3.1 信頼性・耐障害性
- **HTTP通信の例外処理**:
  - 接続エラー（`requests.exceptions.ConnectionError`）、タイムアウト（`requests.exceptions.Timeout`）、HTTPステータス異常（`HTTPError`）を捕捉し、異常終了時にエラーログをコンソール出力すること。
  - `response.raise_for_status()` を呼出し、200 OK以外のレスポンスを検知すること。
- **データ件数の検証**:
  - 抽出された映画タイトルの総数が厳密に100件であるかのアサーション/バリデーションを実施すること。

### 3.2 性能・タイムアウト制約
- **ネットワークタイムアウト**:
  - アーカイブサーバの応答遅延を考慮し、リクエストに `timeout=15` 秒を設定すること。

### 3.3 環境互換性・文字コード
- **エンコーディング**:
  - Windows環境（Shift_JIS / CP932）での `UnicodeEncodeError` を防止するため、ファイル書き込み時は必ず `encoding="utf-8"` を明示すること。

## 4. データ仕様・制約

### 4.1 主要数値・パラメータ
| 項目 | 設定値 / 期待値 | 備考 |
| :--- | :--- | :--- |
| **対象URL** | `https://web.archive.org/web/20200518073855/https://www.empireonline.com/movies/features/best-movies-2/` | Wayback Machineスナップショット |
| **抽出期待件数** | `100` 件 | 1位〜100位の映画 |
| **タイムアウト値** | `15` 秒 | `requests.get(..., timeout=15)` |
| **出力ファイル名** | `movies.txt` | カレントディレクトリに出力 |

### 4.2 出力フォーマット仕様
各行に映画タイトルを1件ずつ出力する。書式は元のタイトルフォーマット（例: `1) The Godfather` または `1: The Godfather`）を尊重し、昇順で記録する。

```text
1) The Godfather
2) The Empire Strikes Back
3) The Dark Knight
...
100) Stand By Me
```

### 4.3 境界値・エッジケース対策
1. **順序の反転**:
   - Webページ上のDOM要素は100位から1位の降順で配置されているため、抽出後にスライス `[::-1]` または `reversed()` による反転が必須。
2. **タイトル文字列のノイズ**:
   - 前後に余分な空白文字や改行が含まれる可能性があるため、必ず各要素に `.strip()` を適用する。
3. **特殊記号・アクセント文字**:
   - 欧州映画等のタイトルに含まれる特殊文字（例: `Amélie` や引用符）を欠損なくUTF-8で保存する。

---

## 5. テスト仕様・検証基準 (Acceptance Criteria)

1. **実行結果検証**:
   - スクリプト実行後、同一ディレクトリに `movies.txt` が生成されること。
2. **データ整合性検証**:
   - `movies.txt` の総行数が100行であること。
   - 1行目が「1位」の映画タイトルであり、最終行が「100位」の映画タイトルであること。
3. **文字化け・例外検証**:
   - Windows環境で文字化けなくテキストエディタ等で閲覧可能であること。
   - ネットワーク遮断時、適切なエラーメッセージを出力して制御された終了をすること。
