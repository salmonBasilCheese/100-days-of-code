# 要件定義書: Snake Game (スネークゲーム)

## 1. 目的
Pythonの `turtle` モジュールを用い、グリッドベースで自動前進するヘビを操作してエサを食べ、自己衝突および壁衝突を回避しながらスコアを競う古典的アーケードゲーム「Snake Game」を実装する。

---

## 2. 画面・データ仕様

### 2.1 主語・インターフェース
* **ウィンドウ設計**:
  * 幅（width）: 600px、高さ（height）: 600px（固定）。
  * 背景色: 黒（Black）。
  * ウィンドウタイトル: `"Snake Game"`
* **グリッド基準と基本スケール**:
  * 基本グリッド単位: **20px**。すべてのオブジェクトの配置・移動はこの20の倍数に同期させる。
* **ヘビ（Snake）の初期仕様**:
  * 体の構成: 3つのセグメント（四角形 `square`、白 `white`、サイズ 20×20px）。
  * 初期座標:
    * 頭（Segment 0）: $(0, 0)$
    * 胴体1（Segment 1）: $(-20, 0)$
    * 胴体2（Segment 2）: $(-40, 0)$
  * 初期進行方向: 東（右向き、角度 $0^\circ$）。
* **エサ（Food）の初期仕様**:
  * 形状: 円（`circle`）、色: 青（Blue）または赤（Red）、サイズ: 直径10px（`shapesize(0.5, 0.5)`）。
  * 配置ルール: 壁（$\pm 300\text{px}$）へのめり込みを防ぐため、$-280 \sim 280\text{px}$ の範囲内で**「20の倍数」からランダムに選定された $(x, y)$ 座標**に配置。
* **スコアボード（Scoreboard）の仕様**:
  * 専用タートルを使用。画面上部中央 $(0, 260)$ に白文字で `"Score: 0"` を表示。

### 2.2 境界制約
* **壁衝突判定**:
  * 頭の中心座標が $x > 280$、 $x < -280$、 $y > 280$、または $y < -280$ に達した瞬間にゲームオーバーと判定する。
* **自己衝突判定**:
  * 頭（Segment 0）と、首以降の全セグメント（`segments[1:]`）とのユークリッド距離を判定。
  * いずれかのセグメントとの距離が $10\text{px}$ 未満になった瞬間にゲームオーバーと判定する。
* **ゲームオーバー時の画面状態**:
  * ヘビの移動を即座に完全停止させる。
  * 画面中央 $(0, 0)$ に `"GAME OVER"` を赤色または白色、太字、24pxで表示する。

## 3. 操作・ロジック仕様

### 3.1 入力系統と排他制御
* **キーバインド**:
  * `Up` または `w`: 上（$90^\circ$）へ方向転換
  * `Down` または `s`: 下（$270^\circ$）へ方向転換
  * `Left` または `a`: 左（$180^\circ$）へ方向転換
  * `Right` または `d`: 右（$0^\circ$）へ方向転換
* **同時押し・逆走排他制御（インターロック）**:
  1. **複数キー同時押し**: 同一フレーム内で2つ以上の方向キーが同時に押下されている場合、入力を無効化（直前の進行方向を維持）。
  2. **180度逆走禁止**:
     * 現在「上」進行時: 「下」入力は無視。
     * 現在「下」進行時: 「上」入力は無視。
     * 現在「左」進行時: 「右」入力は無視。
     * 現在「右」進行時: 「左」入力は無視。

### 3.2 追従および成長ロジック
* **自動前進（追従アルゴリズム）**:
  * 毎更新フレーム（0.1秒ごと）、最後尾のセグメントから順に「1つ前のセグメントの現在位置」へ移動させる（インデックス `len - 1` から `1` まで逆順移動）。
  * 最後に頭（Segment 0）を現在の進行方向へ厳密に $20\text{px}$ 前進させる。
* **エサ捕獲と成長**:
  * 頭とエサの距離が $15\text{px}$ 未満になった場合:
    1. スコアを `+1` し、スコアボードを再描画。
    2. エサを別のランダムなグリッド座標（20の倍数）へ再配置。
    3. 現在の最後尾セグメントの位置に新しいセグメント（四角形、白）を追加（`append`）して体を伸ばす。

## 4. 例外・非機能要件

### 4.1 異常系防御
* **エサの体内リスポーン防止**:
  * エサの再配置時、ヘビのいずれかのセグメントと全く同じ座標にエサが重なった場合は再抽選を行う。
* **ウィンドウ閉じ時の安全性**:
  * 実行ループ中にウィンドウの「×」ボタンが押された場合、`turtle.Terminator` 例外をキャッチして正常終了させる。

### 4.2 パフォーマンス
* `screen.tracer(0)` を使用してタートル個別の描画アニメーションを完全に無効化する。
* 全セグメントの移動計算が完了した後に `screen.update()` を1度だけ呼び出し、チラつき（フリッカー）のないスムーズな描画を保証する。
* フレーム間のウェイトは `time.sleep(0.1)` に固定し、操作性を担保する。
