# requirements.md

## 1. プロジェクト概要
Bootstrap テンプレート（Clean Blog）をベースに、Flask および Jinja2 を用いて動的にブログ記事を表示・ルーティングするマルチページ対応の Web アプリケーションを構築する。

---

## 2. システム要件 & 仕様設計

* **主要な数値・表示仕様**
  * **レスポンシブ・ブレークポイント**: Bootstrap 基準に準拠（モバイル: `< 576px`、タブレット: `768px`、PCデスクトップ: `992px` 以上でナビゲーションバーをトグル表示から水平展開へ切り替え）。
  * **タイトル・ヘッダー表示領域**: 各ページのメインヘッダーはビューポート幅 100%（全画面幅）で展開し、背景画像は `background-size: cover`、最小高さ `200px`（モバイル）〜 `350px`（デスクトップ）を維持。
  * **記事リストの表示件数**: API 取得件数に依存（標準 3 件〜 10 件程度を想定、Day 59 初期仕様では全件一括ループ描画）。

* **境界値・例外エラー仕様**
  * **記事 ID（ルーティング境界値）**: `/post/<int:index>` へのアクセス時、該当する `id` が API レスポンス内に存在しない場合（例: `id <= 0` や未定義のインデックス）、サーバーダウンを防ぎ HTTP 404（Not Found）を返却。
  * **API 疎通エラー（タイムアウト・サーバーダウン）**: 記事データ取得用 API（Npoint など）へのリクエスト失敗（HTTP 5xx、接続拒否、タイムアウト 5 秒超過）時は、空リストへのフォールバックまたはエラーハンドリングを実施。
  * **静的アセット解決**: CSS/JS/画像パスは相対参照を禁止し、すべて Flask の `url_for('static', filename='...')` で統一解決。不正なファイル名呼び出し時の 404 を防止。

* **データ構造・制約仕様**
  * **必須キー制約**: API から返却される JSON 各記事オブジェクトは、以下のスキーマを必須保持。
    * `id` (int): ユニーク識別子
    * `title` (str): 記事タイトル（未設定時はフォールバック文字列を適用）
    * `subtitle` (str): サブタイトル
    * `body` (str): 記事本文
  * **文字列長制約**: タイトルが極端に長い場合（100 文字超過）でもヘッダーレイアウトが破綻しないワードラップ設定（`overflow-wrap: break-word`）。
  * **HTML エスケープ制御**: 記事本文（`body`）に HTML タグが含まれる場合の Jinja2 エスケープ挙動（プレーンテキストとして扱うか、`| safe` フィルタを適用するか）の事前整合。

## 3. 画面・ルーティング一覧

| エンドポイント | メソッド | テンプレート | 主な機能 |
| :--- | :--- | :--- | :--- |
| `/` | GET | `index.html` | 記事一覧の表示、ヘッダー（home-bg）描画 |
| `/about` | GET | `about.html` | About ページの表示、ヘッダー（about-bg）描画 |
| `/contact` | GET | `contact.html` | お問い合わせフォームの表示、ヘッダー（contact-bg）描画 |
| `/post/<int:index>` | GET | `post.html` | ID に合致する個別記事の詳細表示、ヘッダー（post-bg）描画 |

---

## 4. 共通コンポーネント構成
* `header.html`: `<head>` タグ、Bootstrap CSS 読み込み、レスポンシブ対応ナビゲーションバー
* `footer.html`: ソーシャルリンク、コピーライト、Bootstrap JS / scripts.js 読み込み
* テンプレート分割により、各ページ（`index.html`, `post.html` 等）はヘッダー・フッターをインクルードまたはブロック継承してコードの重複を排除。
