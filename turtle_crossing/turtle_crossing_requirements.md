# システム要件定義書: Turtle Crossing Game (Day 23)

## 1. 主語・インターフェース (Actors, Dimensions & Interfaces)

### 1.1 画面構成 (Screen)
* **解像度**: 幅 600px × 高さ 600px
* **座標系**: 原点 `(0, 0)` を画面中央とするデカルト座標系
  * X軸: `[-300, 300]`（左端: -300, 右端: 300）
  * Y軸: `[-300, 300]`（下端: -300, 上端: 300）
* **背景色**: 白 (`"white"`)
* **エリア定義**:
  * スタート安全地帯: $y \in [-300, -240]$
  * 車道エリア: $y \in [-240, 240]$
  * ゴール安全地帯: $y \in [240, 300]$

### 1.2 オブジェクト仕様
* **プレイヤー (Player / Turtle)**:
  * クラス責任: 自身の描画、上方向移動、初期位置リセット、ゴール到達判定。
  * 形状・色: `"turtle"`, 黒 (`"black"`)
  * 物理サイズ: 20px × 20px
  * 向き: 北（上向き、`heading = 90`）
  * 初期スポーン位置: `(0, -280)`
  * 移動ステップ量: 10px / input tick
  * 操作可能キー: `Up`（上矢印キー）のみ。下方向・左右への移動は不可（仕様として排他）。
* **車群 (CarManager & Car)**:
  * クラス責任: 車インスタンスの生成・カラー選定、横方向移動、画面外オブジェクトの破棄、レベルに応じた速度スケーリング。
  * 形状: `"square"` を `stretch_wid=1, stretch_len=2`（幅 40px × 高さ 20px）に変形。
  * カラーパレット (12色):
    `["red", "blue", "green", "orange", "purple", "yellow", "teal", "magenta", "coral", "crimson", "gold", "dodgerblue"]`
    ※ 生成時にこの12色からランダムに1色選定。
  * 生成スポーン位置: 画面右端外 `x = 300`、Y軸は車道エリア $y \in [-240, 240]$ の範囲からランダム（または離散レーン配置）。
  * 進行方向: 西（左向き、右から左へ移動）。
  * 初期移動速度: 5px / tick
* **スコアボード (Scoreboard)**:
  * クラス責任: 現在レベルの表示、レベル更新、ゲームオーバー表示。
  * 表示位置: 左上 `(-280, 260)`
  * 初期値: `Level: 1`
  * フォント: Courier, 18pt, bold (通常表示) / 24pt, bold (ゲームオーバー表示)

### 1.3 操作インターフェース
* **キー入力**:
  * `Up` (上矢印キー): プレイヤーが上方向（北）へ 10px 移動。
  * 下・左・右キーはバインドせず、移動入力を一切受け付けない。

## 2. 境界制約 (Boundary Conditions & Invariants)

### 2.1 プレイヤーの可動域とゴール判定
* プレイヤーは `(0, -280)` から開始し、前進のみ可能。
* **ゴール判定境界**:
  $$y \ge 280$$
* $y \ge 280$ に到達した瞬間にレベルクリアと判定し、プレイヤースポーン位置 `(0, -280)` へ即座にリセットする。

### 2.2 車オブジェクトのライフサイクルとメモリ境界
* 車インスタンスは右端 `x = 300` で生成され、左端へ移動する。
* **画面外破棄境界**:
  $$x < -320$$
* $x < -320$ に到達した車インスタンスは、画面描画から隠蔽（`hideturtle()`）し、管理リストから参照を完全に削除（除外）する。これによりインスタンス蓄積によるメモリリーク・描画遅延を防止する。

### 2.3 衝突判定境界（矩形交差判定）
プレイヤー（20px × 20px）と車（40px × 20px）の当たり判定は、中心座標間の絶対距離によるAABB近似を採用する。
* **衝突検知条件**:
  $$|x_{	ext{turtle}} - x_{	ext{car}}| < 25 \quad 	ext{かつ} \quad |y_{	ext{turtle}} - y_{	ext{car}}| < 20$$
* この条件を満たした場合、車道上での接触とみなし、即座にゲームオーバーシーケンスへ遷移する。

### 2.4 速度スケーリングと上限クランプ（トンネリング防止）
* レベル上昇ごとに車の移動速度を `+2px/tick` 加算する。
* **速度上限境界**:
  $$	ext{car\_speed} \le 16.0	ext{px / tick}$$
* 1フレームあたりの移動量がプレイヤーの幅（20px）を超えて判定を飛び越える現象（すり抜け）を防ぐため、最大速度を 16px/tick にクランプする。

## 3. 操作・ロジック仕様 (State Machine & Logic)

### 3.1 状態遷移 (State Machine)
システムは以下の3状態を持つステートマシンとして動作する。
1. `READY`: 画面構築、プレイヤー初期配置、スコアボード初期化。
2. `RUNNING`: 車の周期的生成・移動、入力処理、衝突・ゴール判定ループ。
3. `GAME_OVER`: プレイヤー衝突、車の移動停止、ゲームオーバー通知、ループ終了。

```
[READY]
   |
   v
[RUNNING] <---------------------------+
   |                                  |
   +---> (ゴール到達: y >= 280)        |
   |           |                      |
   |           v                      |
   |     [LEVEL_UP]                   |
   |     ・レベル +1                   |
   |     ・車速度 +2px                 |
   |     ・プレイヤー位置リセット --------+
   |
   +---> (衝突検知: dx < 25 and dy < 20)
               |
               v
         [GAME_OVER]
         ・メインループ停止
         ・画面中央 "GAME OVER" 描画
```

### 3.2 車の生成ロジック
* メインループの1サイクルごとに乱数（例: `random.randint(1, 6) == 1`）を評価し、確率的に新規車両を生成。
* 新規車両生成時、12色パレットからランダムに色を割り当て、Y座標を `[-240, 240]` の範囲（車道）でランダム決定する。

### 3.3 レベルクリアと難易度更新
* プレイヤーが `y >= 280` に到達した場合：
  1. `scoreboard.increase_level()` を実行（描画更新）。
  2. `player.go_to_start()` を実行（`(0, -280)` へ移動）。
  3. `car_manager.speed_up()` を実行（車の移動量を増加）。

## 4. 例外・非機能要件 (Robustness & Non-Functional Requirements)

### 4.1 パフォーマンス・描画制御
* **トレーサー制御 (`tracer(0)`)**:
  * 自動アニメーションをオフにし、各フレームの処理（車の移動・入力反映・衝突判定）が完了した後に `screen.update()` を1回のみ呼び出す。
  * 固定スリープ間隔（約 0.05秒 〜 0.08秒）を維持し、安定したフレームレートを担保する。

### 4.2 評価順序の保証
メインループ内の評価順序を厳格に固定する：
1. `time.sleep(0.05)`
2. `screen.update()`
3. `car_manager.create_car()`（生成試行）
4. `car_manager.move_cars()`（移動 & 画面外破棄）
5. 衝突判定ループ（衝突時は即 `game_is_on = False`）
6. ゴール到達判定

### 4.3 異常終了のハンドリング
* ユーザーによるウィンドウ「×」閉じ操作に伴う `turtle.Terminator` / `tk.TclError` をキャッチし、コンソールにトレースバックを出力せず安全にプロセスを終了する。

## 5. モジュール構成・クラス責務の分離 (Architecture)

```
turtle_crossing/
├── main.py         # 画面構築、メインループ制御、イベントバインド、終了処理
├── player.py       # Playerクラス (Turtle継承、上移動、ゴール判定、初期位置リセット)
├── car_manager.py  # CarManagerクラス (車の動的生成・12色選定・移動・破棄・速度管理)
└── scoreboard.py   # Scoreboardクラス (Turtle継承、レベル表示、ゲームオーバー通知)
```
