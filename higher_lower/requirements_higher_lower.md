# 要件定義書: Higher-Lower Web Game (Day 55)

## 1. システム概要
本システムは、Flask を用いて構築する数値推測 Web アプリケーションである。
サーバー側で 0〜9 のランダムな数値を生成・保持し、ユーザーが URL パスとして送信した予測値（例: `/5`）と正解値を比較して判定結果（High / Low / Correct）を動的な HTML（文字色および GIF 画像を含む）として返却する。

---

## 2. 開発環境・前提制約
- **対象ファイル**: `server.py`
- **フレームワーク**: Flask (Python 3.10+)
- **実行環境**: ローカル開発サーバー (`http://127.0.0.1:5000/`)
- **Git 運用**: 仮想環境 `.venv` やキャッシュファイル（`__pycache__`）は `.gitignore` で除外し、コミット対象外とする。

---

## 3. 機能要件

### 3.1. ホーム画面（ルート: `/`）
- **エンドポイント**: `GET /`
- **表示内容**:
  - `<h1>` タグ: `Guess a number between 0 and 9`（0 から 9 の間の数字を推測してください）
  - `<img>` タグ: Giphy から取得した待機中アニメーション GIF
    - 推奨 URL: `https://media.giphy.com/media/3o7aCSPqXE5C6T8tBC/giphy.gif`
    - 表示サイズ制限: 横幅 `width="350"` 前後で固定表示
- **乱数生成**:
  - アプリケーション起動時（またはリセット時）に `0` から `9` までの整数乱数を生成して保持する。

### 3.2. 推測値判定画面（ルート: `/<int:guess>`）
- **エンドポイント**: `GET /<int:guess>`
- **入力パラメータ**: `guess`（整数型 URL パスパラメータ）
- **判定ロジックおよびレスポンス仕様**:
  1. **Too High（推測値 > 正解値）**:
     - `<h1>` タグ: `<h1 style="color: purple;">Too high, try again!</h1>`（紫系統などの指定色）
     - `<img>` タグ: 高すぎることを示す GIF 画像
     - 推奨 URL: `https://media.giphy.com/media/3o6ZtaO9BZHcOjmErm/giphy.gif`
  2. **Too Low（推測値 < 正解値）**:
     - `<h1>` タグ: `<h1 style="color: red;">Too low, try again!</h1>`（赤系統などの指定色）
     - `<img>` タグ: 低すぎることを示す GIF 画像
     - 推奨 URL: `https://media.giphy.com/media/jD4DwBtqPXRXa/giphy.gif`
  3. **Correct（推測値 == 正解値）**:
     - `<h1>` タグ: `<h1 style="color: green;">You found me!</h1>`（緑系統などの指定色）
     - `<img>` タグ: 正解を祝う GIF 画像
     - 推奨 URL: `https://media.giphy.com/media/4T7e4DmcrP9du/giphy.gif`

## 4. 非機能要件・境界値・例外設計

### 4.1. 主要な数値とレイアウト仕様
- **乱数生成範囲**: `0` 〜 `9`（`random.randint(0, 9)`）
- **ポート番号**: `5000` (`debug=True` 設定で起動)
- **画像レイアウト制約**: 画面崩れを防ぐため、すべての `<img>` タグに `width="350"` を明示し、`alt` 属性を付与する。

### 4.2. 境界値および例外ハンドリング
| 入力ケース | 入力例 | 想定される挙動・処理方針 |
|---|---|---|
| 最小境界値 | `/0` | 正常処理。判定ロジックで評価されること。 |
| 最大境界値 | `/9` | 正常処理。判定ロジックで評価されること。 |
| 範囲外数値 | `/-1`, `/10` | 判定ロジックとしては Too Low / Too High に流す、もしくは範囲外警告を返す。 |
| 非数値入力 | `/abc`, `/3.14` | Flask の `<int:guess>` コンバータにより、自動的に `404 Not Found` として安全に弾く（サーバー 500 エラーを防止）。 |

### 4.3. データ制約
- **データ型整合性**: URL パラメータから受け取る `guess` と、内部生成された正解値は共に `int` 型として厳密に数値比較（`>`、`<`、`==`）すること。文字列比較（辞書順）を行わないこと。
- **HTML 生成**: テンプレートエンジン（Jinja2）未導入段階のため、文字列フォーマット（f-string 等）を用いて単一のレスポンス文字列として返却すること。
